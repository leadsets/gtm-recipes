# Cursor prompt: write a verified list into the repo

Use after adding Leadsets to `~/.cursor/mcp.json`. Written guide: https://telegra.ph/Using-Leadsets-MCP-lead-data-inside-Cursor-11-20

```
Using the Leadsets MCP tools, check get_usage first.

Find 15 heads of sales at US B2B SaaS companies with 50 to 500 employees.
Write leads.md in this repo with a table of name, title, company, match reasons, email, verification status and checked_at.

Verify every email. Put catch-all and unknown in a second table headed Hold.
Do not invent a status when a check was skipped. Quote request_id at the bottom.
```
